## 2026-09-27 · 002 · 统一构建与安全默认值

- **目标：** 让项目可从统一入口构建，并避免开发版 Agent 自动被原版覆盖。
- **改动：** `scripts/build-frontend.sh` 将 Web UI 打包为 Hub 可嵌入的 `dist.tar.zst`；`Makefile` 构建 Hub 和 Agent；本地启动脚本让 Hub 默认监听 `127.0.0.1:25774`，让 Agent 默认关闭 Web 控制和上游自动更新。Agent 程序自身也默认关闭上游自动更新，并在关闭时拒绝远程版本切换；能力上报按开关调整。默认站点名、命令帮助和页面元数据改为 PierOps。
- **决定：** 在统一授权层完成前，开发启动入口默认只启用监控；终端/文件能力仅显式开启验证。保持功能开关清楚，不把它等同于已完成细粒度权限控制。
- **验证：** 前端打包成功；Hub 与 Agent 均编译成 `bin/pierops-hub`、`bin/pierops-agent`；二进制帮助输出显示 PierOps 名称；打包后的 HTML 标题为 `PierOps`。这些产物不纳入 Git。
- **对应提交：** `87bdde5`。

- **边界：** 尚未用真实 VPS/Agent token 完成端到端连接；未测试生产部署、Docker 或权限隔离。

## 2026-09-27 · 006 · Hub Docker 运行与公开仓库清理

- **目标：** 让 Hub 能由 Docker/Compose 运行，并准备只含可公开内容的 Git 历史。
- **改动：** 新增 `Dockerfile.hub`、`compose.yaml`、`.dockerignore`、固定 Web UI 版本获取脚本及公开仓库检查脚本；调整构建入口、忽略规则、README 和来源记录。Web UI 本地副本继续用于开发，但不进入公开 Git；Hub 默认绑定主机回环地址，容器以 `pierops` 用户运行，数据库使用命名卷。
- **决定：** Hub 容器不挂宿主 Docker socket；节点 Docker 信息待 M3 由 Agent 本机读取。Web UI 快照未见独立许可文件，公开仓库仅记录来源和固定 commit，公开分发带前端的镜像前仍须确认授权。
- **验证：** `docker compose config --quiet`、前端构建、全新 Docker 多阶段镜像构建通过；隔离 Compose 项目 `pierops-test` 运行后容器健康，`/` 返回 307 跳转安装页，`/install` 返回 200；进程用户为 `pierops`，`/app/data/komari.db` 已生成。容器重启后数据库仍在，HTTP 短暂不可用，随后安装页恢复 200 且健康检查通过。`make check-public` 对新公开树通过。构建环境曾因隔离 Colima VM 的 DNS 配置损坏失败，仅修复该测试 VM 的解析配置后重试成功。再次执行 `make test` 时默认沙箱无法写 Go 缓存；放开缓存后依赖下载长时间无进展，停止本轮重跑。此前架构基线的相同 Go 源码测试已通过，本轮未修改 Go 源码。
- **边界：** 尚未在真实 VPS 上验证；未创建管理员账户或连接真实 Agent。公开 GitHub 仓库与推送需在历史清理、安全检查后完成。
- **对应提交：** 本次提交。
