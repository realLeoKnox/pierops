## 2026-10-03 · 009 · M1 授权核心与运维入口

- **目标：** 按用户最新指示暂缓真实 VPS 验收，继续实现用户—节点—动作授权。
- **改动：** 新增 `hub/internal/access`、账户角色、精确节点动作授权表和结构化审计表；接入管理 REST、直接/批量 RPC、WebSocket、终端和文件入口。增加受限用户创建与完整策略替换 API，新增账户密码使用 bcrypt。保留原安装账户 owner 权限，全局 API Key 仍为 owner，受限用户不能管理平台、读取 Agent token 或修改 owner。更新授权文档、阶段状态与本地测试入口。
- **关键决定：** 批量命令在创建任务前检查全部目标；用户不能进入 Agent 的终端、文件数据和上报入口；长期 RPC 连接每次重新检查身份；终端每次输入及空闲五秒周期检查授权。上传续传绑定用户，预览令牌在下载时重新校验原身份。策略与审计快照在同一事务保存；允许操作的审计落库失败时拒绝派发。
- **验证：** Hub 本地编译通过。临时数据库和本机测试服务中的授权核心、REST/RPC/WS 入口、迁移兼容和既有上传/恢复用例通过；覆盖跨节点拒绝、viewer 写操作拒绝、策略撤销、过期会话、API Key 轮换、批量目标预检查和位置参数。`git diff --check` 通过。
- **失败与处理：** 检查发现 SQLite 中不同偏移时区的时间字符串会导致过期比较不准确，改为读取会话后由 Go 时间类型比较；WebSocket 用例首次握手因缺少同源 Origin 被拒绝，补充真实同源请求头后通过，保留 Origin 防护。
- **边界：** 用户暂缓真实 VPS/Agent 验收；未做真实远程终端与文件的端到端运行。公开监控仍由站点公开/私有配置控制，单次文件流执行中暂不撤销；受限账户的完整运维界面与 Agent 本地约束仍需继续开发。下一步加入 owner 授权管理页。
